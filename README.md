# PRODIGY_CYBERSECURITY

## About the Repository

This repository showcases the cybersecurity projects completed during my internship at Prodigy InfoTech. The tasks focus on practical applications of cybersecurity concepts, including cryptography, password security, image encryption, network monitoring, and event logging using Python.

---

## Project List

### Task 01 – Caesar Cipher Encryption

A Python application that encrypts and decrypts text using the Caesar Cipher algorithm by applying a user-defined shift value.

### Task 02 – Image Encryption Tool

An image encryption and decryption tool that performs pixel-level manipulation to secure image data.

### Task 03 – Password Strength Analyzer

A password complexity checker that evaluates password security based on length, character diversity, and common security standards.

### Task 04 – Keyboard Activity Logger

A basic keylogging application developed for educational purposes to understand keyboard event monitoring and system input handling.

### Task 05 – Network Packet Analyzer

A packet sniffing and network monitoring tool that captures and analyzes network packets, displaying protocol information, source and destination addresses, and traffic details.
